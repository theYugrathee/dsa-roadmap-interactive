# 🏆 Interactive 6-Month DSA Roadmap: Zero to Expert

An elite, high-performance, and fully interactive **Data Structures & Algorithms (DSA)** learning roadmap tracking **168 days** of rigorous structured preparation. Designed carefully for clearing technical coding rounds at top-tier product companies (FAANG) and excelling in competitive programming.

> **📱 Mobile First & Zero Dependencies:** Built using vanilla HTML, CSS, and lightweight JavaScript logic. You can easily clone it, drop the `.html` file into your mobile browser, and track your prep seamlessly on the go.

---

## ✨ Features

- **🌐 Dynamic Dual Language System:** Switch instantly between structured configuration baselines for **C++ (STL)** and **Java (Collections Framework)**.
- **📅 Granular 168-Day Matrix:** Divided into 6 logical blocks (Phases), drilling down into weekly core goals and exact daily action tracks.
- **🎯 Milestone Tracker:** Clear progress checkpoints mapping visual skill expectations at the end of each completion cycle.
- **📚 Integrated High-Yield Resources:** Instant access to curated target domains like LeetCode, Codeforces, CSES Problem Set, and TakeUForward.
- **⚡ Accordion Engine UI:** Highly clean, collapsible UX built with modular components that run smooth on low-end mobile devices.

---

## 🗺️ Roadmap Architecture Overview

The curriculum splits into 6 intense sequential tracks designed to compound problem-solving intuition over brute-force memorization:

| Phase | Focal Framework | Core Topics | Targeted LeetCode Competency |
|---|---|---|---|
| **Phase 1** | 🏗️ Foundations | Arrays, Strings, Sorting, Binary Search, Bit Manipulation | Confident with *Easy* Level Problems |
| **Phase 2** | 🔗 Linear Constructs | Linked Lists, Monotonic Stacks, Deques, Core Backtracking | Transitioning into *Medium* Space |
| **Phase 3** | 🌳 Hierarchies | Binary Trees, BSTs, Tries, Max/Min Heaps, Greedy Logic | Fluid Multi-Traversal Mastery |
| **Phase 4** | 🕸️ Graph Networks | BFS/DFS, Dijkstra's, Topological Sorting, Disjoint Set Union (DSU) | Advanced Adjacency Implementations |
| **Phase 5** | ⚡ Dynamic Optimization | 1D/2D DP, Subsequences, Grid Optimization, Bitmasking DP | Complex State Machine Parsing |
| **Phase 6** | 🏆 Strategic Polish | Sweep-Line, Segment Trees, Sparse Tables, Mock Interviews | Interview and *Hard* Pattern Ready |
